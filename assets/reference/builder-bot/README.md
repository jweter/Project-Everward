## What the image shows

A wheeled humanoid-style robot with two articulated arms, a sensor head, and a row of swappable end-effector tools (fastener, nail/staple, drill, cutting, paint, inspection, gripper, material handler). Useful ideas for the game: a tool-dock with automatic tool changing, a stabilising base with outriggers or clamps, force/torque limits and tool interlocks, and a step-by-step job readout with a verification step.
