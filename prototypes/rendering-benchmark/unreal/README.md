# Unreal Prototype C adapter

This directory is the Unreal Engine candidate for Everward Phase 1 Prototype C. It is intentionally an engine adapter, not a second simulation implementation.

## Contract

The adapter reads `Content/benchmark_handoff.json`, generated by the renderer-neutral handoff exporter. Handoff version 2 is the authority for scenario identity, object positions, camera stages, camera dwell times, animation periods, accelerated simulation time, required scene features, and feature bindings.

Canonical spatial values are expressed in metres. Unreal world-space values are centimetres, so the adapter performs an explicit 100× unit conversion at the presentation boundary. The conversion must not leak back into simulation truth.

The adapter must not introduce random scene-state behavior. Asteroid rotation, mining mechanism motion, camera switching, and displayed simulated time all derive from the handoff and elapsed canonical playback time.

## Current slice

This first Unreal slice establishes a buildable C++ project/module shell and the deterministic handoff consumer. `ABenchmarkAdapter` creates renderer-side components for the asteroid, probe, mining mechanism, planet, stellar directional light, camera, and telemetry, then applies canonical state from the handoff.

It does **not** yet constitute decision-grade Unreal rendering evidence. Mesh/material assignment, equivalent visual-feature implementation, particles/volumetrics, capture instrumentation, profiling, screenshots, build-size measurement, and operator evidence still belong to subsequent slices and the canonical capture runbook.

## Preparing the handoff

Generate the self-contained handoff from the repository-level rendering benchmark tooling, then copy the produced JSON to:

`prototypes/rendering-benchmark/unreal/Content/benchmark_handoff.json`

Do not hand-edit the bundle to make Unreal behavior differ from Godot. If the renderer needs additional truth, update the renderer-neutral handoff contract first and apply that same revision to both candidates.

## Verification

The repository's rendering-benchmark unittest discovery includes `test_unreal_adapter.py`. Those tests protect the adapter boundary even on CI hosts that do not have Unreal Engine installed. A real Unreal compile/run remains required before this candidate can produce benchmark evidence.
